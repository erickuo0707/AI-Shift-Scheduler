# AI 排班助手

依 PT 可上班日期、正職休假需求（X 必休／△ 希望休）、每週工時上限與班別偏好，產生可檢視、可匯出的整月排班建議。

## 目前版本

此 MVP 是純前端網頁（React 單頁應用），資料只儲存在使用者目前的瀏覽器，不會上傳到伺服器，也不需要 API 金鑰。預設排下個月，也可以手動選擇其他月份。PT 勾選可以上班日期；正職每月依週數選 4–5 天休假需求，X 為必休、△ 為希望休。排班結果依週分區，左側列出員工、上方列出星期與日期，每個日期格顯示班別代碼與時間；缺額列另外列明。班別可設定時間、休息扣除、每班人數與適用星期。排班引擎遵守必休日期、每週最高工時、最少休息間隔與連續工作日上限，嘗試滿足希望休，再按工時負擔與班別偏好評分。

技能欄位與每週目標工時欄位已移除。PT 勾選可上班日；正職可標記必休 X、希望休 △，每月建議選 4–5 天，超過時提醒與主管協調。排班會嘗試滿足 △，並優先避開不喜歡的班別；每週最高工時可編輯。班別可設定休息扣除時間，避免把休息時數算進工時。

生成式 AI 對話功能尚未接入；目前先用可解釋的規則與評分引擎處理排班限制，避免偏好覆蓋硬性規則。自然語言需求理解可在後續版本接入安全的伺服器端服務。

## 排班規則（依門市實際班表）

- **正職**：月休天數＝當月紅字天數（週末＋國定假日），休哪幾天不限星期幾；可自選 4–5 天 X 必休／△ 希望休，其餘由系統安排，並確保每週（日～六）至少休 2 天。休假日標「例假日／休息日」。正職在上班日一定優先排班。
- **PT**：只排勾選可上班的日期，依工時比例平衡分配。
- **帶班人員**：每天盡量至少排一位；帶班人員可同天上班或同天休。
- **必要班／選填班**：必要班（如 KC-11、KC-12）沒人時列為缺額；選填班（如 10:30-16 短班）有人能排才排，不算缺額。
- **全天班延長**：某個必要班沒人能上時，把當天已排班的人延長為涵蓋兩班的全天班（如 11:00–21:00，計 9 小時），可超過每週上限，並在工時概覽提醒。
- **國定假日**：內建 2026、2027 年平日放假日（依人事行政總處辦公日曆表），可在「本月紅字」自行點選調整。
- 一週一律以週日到週六計算。

## 技術架構

前端以 React 19 + Vite 建置，樣式使用 Tailwind CSS v4，對話框與提示使用 Motion 做簡單淡入。排班引擎位於 `src/lib/scheduler.js`，畫面元件在 `src/components/`。

## 開啟與部署

本機開發：

```bash
npm install
npm run dev
```

建置：`npm run build`，輸出在 `dist/`。

部署成可分享網址：

1. 到 repository 的 **Settings → Pages**。
2. 在 **Build and deployment → Source** 選擇 **GitHub Actions**。
3. 推送到 `main` 會自動部署；也可在 **Actions** 手動執行 `Deploy to GitHub Pages`。
4. 網址：<https://erickuo0707.github.io/AI-Shift-Scheduler/>。

## 隱私

人員姓名與排班資料預設只保存在本機瀏覽器的 Local Storage。請勿在公用裝置輸入不適合留存的個人資料。
